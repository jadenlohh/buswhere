# buswhere?

A website to get real-time bus arrival data in Singapore

Made using [Next.js](https://nextjs.org) together with [tailwindcss](https://tailwindcss.com) and hosted on [Vercel](https://vercel.com)

## Attribution

All data are obtained from [LTA DataMall](https://datamall.lta.gov.sg/content/ltagov/en.html) and [sgbusdata](https://github.com/cheeaun/sgbusdata)
